Privacy Policy

CurioByte · Last updated 26 October 2026

CurioByte is a personal tool run by one developer to publish videos on the developer’s own YouTube channel. This policy explains what Google user data the tool accesses and how it is handled.

Google user data we access

CurioByte asks Google for permission to manage the developer’s own YouTube account (the YouTube scope). It uses that permission only to upload videos to that channel and to check the status of videos it uploaded. It does not read, download or analyse anyone else’s data.

Data from visitors

This website collects nothing from visitors. It has no forms, accounts, cookies, advertising or analytics. It is hosted on GitHub Pages, which may keep standard server logs under GitHub’s privacy statement.

How credentials are stored

The login token that lets CurioByte upload to the developer’s channel is stored as an encrypted secret in a private code repository. It is used only by the tool’s scheduled upload job.

Sharing and transfer

We do not sell, share or transfer Google user data to anyone. CurioByte’s use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

YouTube API Services

CurioByte uses YouTube API Services. By using it, the developer is bound by the YouTube Terms of Service, and Google’s handling of data is described in the Google Privacy Policy. Access can be withdrawn at any time at myaccount.google.com/permissions.

Changes and contact

If this policy changes, the new version will appear on this page with a new date. Questions can be sent by opening an issue on the GitHub repository that hosts this site.
